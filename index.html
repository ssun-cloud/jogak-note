기록 백업·관리

로컬 모드에서는 기존 v1~v3 기록을 같은 브라우저 저장소에서 읽습니다. Supabase 시험 모드는 별도로 로그인해 불러오며, 로컬 기록을 자동으로 전송하거나 합치지 않습니다.

백업 권장

중요한 시험 기록을 남긴 경우 JSON 파일로 내보내 보관하세요. 백업 파일에도 메모 내용이 그대로 들어 있으니 안전하게 관리해 주세요.

사람별 보기와 공식 기록 처리 표시는 이 웹앱의 기능이며, 원본 시트를 변경하지 않습니다.

CSV는 기존 시트 열 구조를 참고한 수동 내보내기용입니다. 구글 시트에 자동 연결되지는 않습니다. 실명·상담 내용이 포함되지 않은 시험 데이터만 내보내세요.

가져오기는 기존 데이터와 합쳐집니다. 기록 ID가 같으면 가져온 기록을 우선해요.

동기화 시험실

현재: 이 기기에만 저장

기관 승인을 받기 전에는 가상 메모만 입력하세요. 로컬 기록과 원격 기록은 완전히 구분됩니다.

절대로 service_role/secret 키를 넣지 마세요. 승인받은 별도 테스트 프로젝트와 가상 데이터만 사용하세요. 웹앱을 공개 배포할 때도 이 원칙이 필요합니다.

인증된 계정의 원격 기록만 표시됩니다. 같은 탭에서 새로고침해도 연결을 자동 복구합니다. 브라우저 탭을 닫거나 로그아웃하면 다시 로그인해야 합니다.

연결된 구글 시트는 읽기만 했으며 수정하지 않았습니다. 실제 당사자 상담 메모나 민감한 업무정보는 기관 승인 저장환경과 접근권한·보관 기준이 확정되기 전에는 입력하지 마세요.
